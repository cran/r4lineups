Introduction

Eyewitness identification data can be analyzed using multiple theoretical frameworks, each providing different information. This vignette demonstrates how to use r4lineups’ model comparison framework to fit and compare:

  1. 2-HT Model (Winter et al., 2022): Multinomial Processing Tree model
  2. EIG (Starns et al., 2023): Expected Information Gain
  3. Full ROC (Smith & Yang, 2020): Receiver Operating Characteristic

The compare_models() function provides a unified interface for fitting all models and generating comparison tables and visualizations.

The Three Models

2-HT Model: Latent Cognitive Processes

The Two-High Threshold (2-HT) model is a multinomial processing tree (MPT) that separates identification decisions into distinct latent processes:

Parameters:

  • dP: Detection of culprit presence (0-1)
  • dA: Detection of culprit absence (0-1)
  • b: Biased suspect selection (0-1)
  • g: Guessing-based selection (0-1)

Model equations (target-present):

  • P(suspect ID) = dP + (1-dP) × [b + (1-b) × g × (1/L)]
  • P(filler ID) = (1-dP) × (1-b) × g × ((L-1)/L)
  • P(reject) = (1-dP) × (1-b) × (1-g)

Use when:

  • You want to understand underlying cognitive mechanisms
  • Testing theories about detection vs. guessing
  • Comparing conditions with different bias levels

EIG: Information-Theoretic Measure

Expected Information Gain quantifies how much information witness responses provide about guilt vs. innocence using Shannon entropy:

Formula: EIG = Σ p(x) × [H(prior) - H(p(guilty|x))]

where x = response category (e.g., “suspect_high_confidence”)

Interpretation:

  • EIG = 0: No information (responses don’t distinguish guilty/innocent)
  • The maximum is the prior entropy, reached when every response resolves guilt completely. That is 1 bit only when the prior probability of guilt is .5; at a prior of .1 it is about .47 bits. Compare EIG values only at the same prior.
  • Higher EIG = more diagnostic procedure

Use when:

  • Evaluating overall diagnosticity of procedures
  • Comparing different identification methods
  • Assessing policy-relevant cutoffs

Full ROC: Investigator Discriminability

Full ROC uses ALL witness responses (suspect IDs, filler IDs, rejections) to compute a threshold-free measure of discriminability:

Measure:

  • AUC (Area Under the Curve)
  • Range: 0 to 1. A value of .5 is the no-discrimination reference, not a lower bound: with the a-priori ordering a procedure that does worse than chance gives an AUC below .5.

Use when:

  • Measuring investigator discriminability
  • Comparing system variables (lineup procedures)
  • Need threshold-free performance measure

The c_criterion = 0.9 is not incidental: getting it wrong makes one of the three models impossible to fit.

c_criterion is a threshold on the maximum of the lineup members’ memory strengths, not a textbook signal-detection criterion. The maximum of six draws from a standard normal averages about 1.27, so a criterion of 0 — the function default — is cleared by almost every lineup, and produces a rejection rate near zero:

The 2-HT model’s detect-absence parameter dA is identified almost entirely by rejections — it is the probability of correctly concluding the culprit is absent. Here only one witness in 600 rejects, so the likelihood carries almost no information about dA and the fit fails; fit_winter_2ht() stops with a message naming that cause. A low rejection percentage is not by itself fatal in a large sample; the information about dA depends on the number of rejections.

Method-Choice Guidance

These methods estimate different quantities; their displayed numbers are not a common model-selection scale and the wrapper does not declare a “best model.”

When to Use Each Model

Use 2-HT when:

  • Testing cognitive theories (detection, guessing, bias)
  • Need to separate memory from response bias
  • Comparing procedures that might differ in bias
  • Want to understand latent psychological processes

Use EIG when:

  • Evaluating overall diagnosticity
  • Comparing identification procedures
  • Need a single summary measure
  • Want information-theoretic interpretation

Use Full ROC when:

  • Need threshold-free discriminability measure
  • Comparing system variables
  • Want to use all available information
  • Policy/practical decision-making focus

Comparing Model Fits

The 2-HT fit reports AIC/BIC, but these values are comparative rather than absolute. They can only be compared with alternative likelihood models fitted to the same observations and outcome representation; they cannot be compared with EIG or AUC. A single-condition 2-HT fit is saturated: it has zero residual degrees of freedom, so it reproduces the observed counts exactly and its absolute fit cannot be tested.

#> 2-HT Model Fit:

#>   AIC: 1123.62

Sensitivity to the Generating d′

A single fit tells you little. A useful check is whether the 2-HT parameters move as the generating d′ moves. The data come from a signal detection (MAX) model, not from the 2-HT model, so there are no true 2-HT parameter values to recover:

recovery <- do.call(rbind, lapply(c(0.5, 1.0, 1.5, 2.0, 2.5), function(dp) {
  d <- as.data.frame(simulate_lineup_data(
    n_tp = 400, n_ta = 400, d_prime = dp, c_criterion = 0.9,
    lineup_size = 6, conf_levels = 5,
    foil_bias = c(0.4, 0.2, 0.0, -0.4, -1.0), seed = 500 + round(10 * dp)
  ))
  fit <- fit_winter_2ht(d, lineup_size = 6,
                        target_present = "target_present",
                        identification = "identification")
  data.frame(`True d'` = dp,
             `Fitted dP` = round(fit$parameters[["dP"]], 3),
             `Fitted dA` = round(fit$parameters[["dA"]], 3),
             check.names = FALSE)
}))

knitr::kable(
  recovery, row.names = FALSE,
  caption = "2-HT detection parameters fitted to data simulated from a signal detection model at known d', 400 lineups per arm."
)

dP increases monotonically with the generating d′. That shows the parameter is sensitive to memory strength. It is not parameter recovery: dP is not on the same scale as d′, the generating model is not the 2-HT model, and the check says nothing about bias, interval coverage or whether the process interpretation is correct. Recovery would need data simulated from fit_winter_2ht()’s own equations.

b is the probability that a witness who detects nothing picks the suspect because the suspect stands out. An interval clearly above zero is a reason to inspect the lineup; how large a b is acceptable is a policy judgement that the model cannot make. Note that the interval is a Wald interval clipped to [0, 1]; boot_winter_2ht() gives bootstrap intervals that respect the boundary.

Detection and guessing are separately identified here, which is the point of the model: an identification rate on its own cannot tell you whether witnesses recognised the culprit or simply picked someone plausible. Note that dP and g are probabilities of different events and are not in competition — a procedure can have both high detection and a high tendency to choose when detection fails.

Interpretation Guidelines

This vignette deliberately gives no poor/moderate/good bands for the 2-HT parameters, EIG or AUC. No study has calibrated such bands, and cut-offs of that kind would read as findings when they are conventions. Interpret each estimate on its own scale, with its uncertainty and its assumptions:

  • 2-HT parameters are probabilities of latent states. Compare them across conditions, ideally with parameters constrained across conditions so that the differences can be tested.
  • EIG runs from 0 to the prior entropy, which depends on prior_guilt (1 bit only at .5). Compare procedures at the same prior.
  • Full-ROC AUC lies between 0 and 1, with .5 the no-discrimination reference. The default diagnosticity ordering is optimistically biased (see Technical Details), so compare procedures with the a-priori ordering.

The summary’s identification note is the part to read. With one target-present and one target-absent condition the 2-HT model has zero residual degrees of freedom, so it reproduces the counts exactly and there is no goodness-of-fit test to read. Convergence, identifiability (enough rejections to estimate dA) and fit are separate questions. Fit can be tested only with several conditions and parameters constrained across them, as in Winter et al. (2022).

Technical Details

What each model estimates, and on what scale

The three models are not three estimates of one quantity, and cannot be ranked against each other directly.

Model Estimand Scale Inference available
2-HT Latent probabilities of detection, bias and guessing Four probabilities in [0, 1] Standard errors from the observed information matrix; bootstrap intervals via boot_winter_2ht(). No fit test for a single condition (zero residual df)
EIG Expected reduction in uncertainty about guilt Bits, 0 to the prior entropy None in this package. Tuttle, Starns and Cohen (2025) give 95% credible intervals for EIG from a Bayesian multinomial model of the response proportions; adding this is planned
Full ROC Investigator discriminability AUC in [0, 1], .5 = no discrimination None in this package; see the note on ordering bias below

2-HT estimation

The model is a multinomial processing tree. Response probabilities are as given in the introduction, and the parameters are estimated by maximum likelihood over the six observed cell counts (three responses by two lineup types). The target-present and target-absent totals are fixed, so the data have 2 × (3 − 1) = 4 degrees of freedom, the same as the number of parameters: a single-condition fit is saturated, with zero residual degrees of freedom (Winter et al., 2022, Figure 1). The standard errors measure how sharply the data pin each parameter down. At the best-fitting values, the log-likelihood falls away steeply in some directions and gently in others; that curvature, the Hessian matrix of second derivatives, is computed numerically, and its inverse gives the sampling variances of the estimates. A flat likelihood (little curvature) means a large standard error. Winter et al. (2022) describe the model and its estimation in full.

Identifiability. The detect-absence parameter dA is identified almost entirely by rejections. If very few witnesses reject, the likelihood is close to flat in dA and the optimiser fails. fit_winter_2ht() checks for this and reports it as such, rather than failing with a message about non-finite differences.

EIG

Expected information gain is computed over the observed response categories with the prior supplied by prior_guilt. Because it is an expectation over a set of categories estimated from the data, it inherits the binning issue discussed in vignette("calibration_decision_analysis"), and it has no standard error here.

Full ROC

Computed as described in vignette("fullroc_analysis"). The default ordering by sample diagnosticity ratio is optimistically biased, because the ordering is estimated from the same data used to compute the area; on data with no signal at all it returns AUC near 0.65 at 100 lineups per arm. compare_models() uses the default ordering, so treat the AUC it reports as an upper bound rather than an estimate, and refit with order = "apriori" for anything inferential.

Assumptions common to all three

  1. Each witness contributes one response, so the response categories partition the sample.
  2. Target-present and target-absent lineups are independent samples.
  3. All lineup members other than the suspect are functioning foils. Where some members are implausible alternatives, the effective lineup size is smaller than the nominal lineup_size passed here, and all three models will be misspecified in the same direction. A member nobody chose in the sample is not necessarily such a foil: in a fair six-person lineup, a given member receives no choices from ten witnesses with probability (5/6)^10 ≈ .16. Fitzgerald, Tredoux and Juncu (2023) discuss correcting error-rate estimates for unequal foil choices by using effective rather than nominal size; passing an effective size to these models is planned for a future version.
